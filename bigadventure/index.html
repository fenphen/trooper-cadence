☁️ Family sync

Without sync, each phone keeps its own scores. To play as one family, connect all four phones to the same free Firebase database. Takes about five minutes once.
How to set it up
  1. Go to console.firebase.google.com, sign in with a Google account, and Add project (any name, Analytics off).
  2. In the left menu open Build → Realtime Database → Create database. Pick a location, choose Start in test mode.
  3. In the Rules tab replace the rules with the block below and Publish. Only someone who knows your family code can read or write.
  4. Copy the database URL shown at the top of the Data tab (looks like https://something-default-rtdb.firebaseio.com) and paste it below, together with a family code you make up.
  5. Share this page's link with the family. Each person pastes the same URL and code once.
{
  "rules": {
    "families": {
      "$code": {
        ".read": "$code.length >= 8",
        ".write": "$code.length >= 8"
      }
    }
  }
}

📲 Put it on your phone

iPhone (Safari): tap the Share button, then Add to Home Screen.
Android (Chrome): tap the ⋮ menu, then Add to Home screen or Install app.
